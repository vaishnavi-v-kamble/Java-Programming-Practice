# Java Basic Programs 🚀

This repository contains simple Java programs created to practice and strengthen fundamental programming concepts.

# Programs Included

1. **Hello World** – Basic Java program to understand program structure and output.
2. **Age Voting Check** – Checks voting eligibility based on age.
3. **Even or Odd** – Determines whether a number is even or odd.
4. **Anagram** – Checks whether two words are anagrams.
5. **Profit or Loss** – Determines whether a transaction results in profit or loss.
6. **Positive or Negative** – Checks whether a number is positive or negative.

These programs help develop understanding of **variables, data types, user input, operators, conditional statements, strings, and basic problem-solving**.

This repository is part of my journey to improve my **Java programming and logical thinking skills** and build a strong foundation for **DSA and software development**.
